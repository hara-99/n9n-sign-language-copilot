LAYER 7 CORE

5-Way AI Decision State Machine

SPEAK

The AI Decision Engine continuously arbitrates whether to vocalize, hold for further temporal context, request user clarification, self-correct previous tokens, or trigger emergency alerts.

🔊

SPEAK

Confidence ≥ Threshold and complete sign/phrase held. Vocalizes with minimum delay.

Trigger: Conf ≥ 75%, Hold ≥ Target ms
⏳

WAIT

In-progress sign transition or incomplete sequence. Accumulates temporal buffer without interrupting.

Trigger: Hold < Target ms or Active Motion
❓

CLARIFY

Ambiguous gesture pair (e.g. M/N, A/S). Prompts visual disambiguation choices.

Trigger: 45% ≤ Conf < 75%
✨

CORRECT

Self-Correcting AI retroactively updates earlier interpretations when context shifts.

Trigger: N-Gram Context Mismatch
🚨

ALERT

Critical trigger detected (e.g. Help, Pain, Danger). Immediate alarm and priority vocalization.

Trigger: Emergency Keyword Match
